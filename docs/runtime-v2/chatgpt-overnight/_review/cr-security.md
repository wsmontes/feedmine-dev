## Verificado sem achado (para não repetir trabalho)

- **Segredos**: nenhum segredo, chave ou token em arquivo rastreado nem no histórico. `git ls-files | grep -Ei 'AuthKey|\.env|\.p8|\.p12|mobileprovision'` só devolve `PublicationToken.swift` e `DesignTokens.swift` (falsos positivos de nome); `git log --all -p --diff-filter=A` por esses nomes é vazio; não há `sk-…`/`hf_…`/`ghp_…`/`AIza…` hardcoded (`DEEPSEEK_API_KEY` vem só de env/.env; `sk-...` é placeholder em docstring). O `.env` do worktree não tem chave de API — só identificadores ASC, que não são secretos.
- **Caminho privado em arquivo rastreado**: 117 arquivos com `/Users/wagnermontes/…` (docs, relatórios e os 101 logs de S-09). Sem impacto de credencial; tratado em S-09.
- **Zip Slip / download de conteúdo arbitrário no catálogo**: `CatalogUpdateManifest.validate()` exige `isSafeOPMLPath` (`Feeds/`, `.opml`, sem `..`, sem componente vazio) antes de `appending(relativePath:)` decompor por `/`; conteúdo baixado é conferido contra `bytes` + `sha256`, com tetos de 5 MB (manifesto) e 20 MB (feed). Sem traversal. O problema ali é a assinatura (S-02), não o path.
- **Import de OPML (`file://`, `data:`)**: `OPMLParser.swift:806-808` e `ImportPipeline.swift:150-152` exigem scheme http/https, e o probe exige `HTTPURLResponse` (`ImportPipeline.swift:296-299`) — esquema local não vira fonte.
- **Pacote `Packages/FeedRuntimeV2`**: `EndpointPolicy.validate` (EndpointPolicy.swift:39-66) recusa scheme ≠ http(s), host ausente e credenciais embutidas, e faz upgrade http→https; `PolicyEnforcingHTTPTransport` é ephemeral/sem cache e não segue redirect (PolicyEnforcingHTTPTransport.swift:18-24,38-58). Nenhum segredo, `http://` fixo ou `FileManager` destrutivo nas Fontes.
- **ATS/TLS**: sem `NSAllowsArbitraryLoads` e sem `NSAllowsArbitraryLoadsInWebContent`; nenhuma `NSExceptionDomains`; o teste/UITest plists não têm ATS. O único furo é S-06.
- **Permissões x manifesto**: `Info.plist` não declara nenhuma usage description (`NSCamera*`, `NSLocation*`, `NSContacts*`, `NSPhotoLibrary*`, `NSUserTracking*` ausentes) — nada declarado além do necessário. O `PrivacyInfo.xcprivacy` está no target (project.pbxproj:226,485,1067) e cobre as required-reason APIs efetivamente usadas: `UserDefaults` (CA92.1) e `FileTimestamp` (C617.1 — `DiskImageCache.swift:33,40-41`, `ImageCache.swift:696`, `ShadowInputBridge.swift:999`); não há `systemUptime`/`mach_absolute_time` (nada de SystemBootTime) nem leitura de espaço em disco. `NSPrivacyCollectedDataTypes` vazio é coerente: nenhum SDK de analytics/IDFA (`firebase|amplitude|mixpanel|sentry|segment|advertisingIdentifier` → 0 no código do app).
- **WebView**: a única é `ArticleReaderView` (S-03); sem `evaluateJavaScript`, `WKUserScript`, `UIWebView` ou `SFSafariViewController` em outro lugar.
- **Workflows e scripts**: `ios-ci.yml` e `editorial-ci.yml` não injetam segredo, não usam `pull_request_target` nem `curl | bash`; nenhum script do repo executa `git push` (o `release-testflight.sh` só cria tag local e aborta em árvore suja, conferindo o SHA dentro do arquivo).
